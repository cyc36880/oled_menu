#目前放弃了对最右侧一列缓冲区的写入，与OLED的 ”异常显示“ 有关。可自行开启并尝试去除该异常

说明>>>
异常显示：
	如果在缓冲区的最右侧一列写入数据，它会显示到最左侧。目前猜测，应该为 SetPos 即把起始写入数据的坐标如（0， 0）
即第0行 第0列， 但OLED自动向右偏移了一个单位，起始的写入位置变成了（0，1）即第0行 第1列；使缓冲区向屏幕写入时造成显示
异常，致使屏幕最左侧无法正常使用

屏幕异常闪烁：
	屏幕在默认状态刷新下，正常显示。当一直按下某一按键时，屏幕出现异常闪烁。由于屏幕刷新过快，还未写入完，就清空了缓
冲区，导致出现闪烁。可以 <不使用> DMA的方式，或尝试增加硬件SPI写入速率，再或软件降低屏幕刷新速度、禁止按键长按，亦或者屏
蔽按键的注册刷新都可以改善或修复该错误
